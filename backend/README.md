# FindMyTrainer API

Spring Boot 3.3 · Java 21 · H2 · Spring Security (JWT).

```bash
mvn spring-boot:run      # http://localhost:8081  (Swagger UI: /swagger-ui.html, H2 console: /h2-console)
mvn test                 # integration tests on in-memory H2
```

Demo accounts, business rules, security model, configuration and the full endpoint list are documented in
[`../docs/backend.md`](../docs/backend.md).
